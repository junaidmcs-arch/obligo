# Obligo 0.1.3 — Android

## What's new

- Personalise Obligo with six colour themes: Forest, Ocean, Violet, Rose, Amber,
  and Slate.
- Pair any palette with Light, Dark, or System display mode.
- Choose from visual previews in Settings → Make Obligo yours.
- Appearance preferences are saved offline and included in JSON backups.
- Older settings and backups keep their display mode and use Forest by default.

## Updating

Install `obligo-0.1.3.apk` over your existing app. Do not uninstall or clear storage.
Your records and backup functionality remain available.

Publish the signed APK and its `.sha256` checksum under tag `v0.1.3`, marked Latest.
The browser/iPhone version updates separately through Cloudflare. Once the web
deployment completes, reopen online and accept the app's update prompt.
